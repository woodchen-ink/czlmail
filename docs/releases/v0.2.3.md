## 笔记编辑与预览

- 实时预览与阅读模式共用 Markdown 渲染和排版，补齐表格、嵌套列表、引用、删除线、代码块及脚注的显示；正在编辑的区块保留源码。
- 图片和 PDF 附件改为在正文区域预览，返回笔记时保留编辑器状态，不再弹出独立预览窗口。
- 正文图片支持单击查看大图；远程图片默认加载，保留失败重试，并且不发送 Referrer。
- 改进 `<br>` 换行、引用式链接、脚注编号与长文脚注正跳/回跳，保留原始 Markdown 内容。
- 修复实时预览区块边界的退格/删除行为，避免将整段正文当作一个原子对象处理。

## 目录与操作入口

- 修复选中文件夹后新建位置被沿用的问题：顶部新建和目录树空白处右键在根目录创建，文件夹右键在该文件夹内创建。
- 目录树支持拖动笔记或文件夹到其他文件夹，拖到空白区可移回根目录；无潜在引用的非空文件夹可整棵移动并保留子项。
- 继续保护涉及链接改写的移动/重命名，不强行移动以免破坏图片或笔记引用。
- 常用图标增加悬停文字提示；导入、导出移至「设置 → 笔记」，目录树顶部仅保留新建笔记、新建文件夹与重命名。

## 笔记编辑体验

- 修复输入时内容被回写成远程旧版本的问题：自动保存同步完成后的回读，遇到读取期间的任何输入都会整次丢弃；仅同步状态变化（待同步→已同步）不再改动编辑器文本。
- 编辑器失去焦点后，所有区块都渲染成 Markdown，不再因为光标停在某一段而保持源码。
- 正在编辑的段落按符号即时渲染：标题、加粗、斜体、删除线、行内代码、链接、引用、无序列表圆点、任务框（可直接点击勾选）、分割线。光标碰到该处时保留标记符号，移开后隐藏。
- 输入 ``` 后立即显示为圆角灰底的代码框，未写结束围栏时也是。
